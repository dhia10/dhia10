- **Valuation Engine:** Predictive pricing model (XGBoost) combined with OpenStreetMap spatial scoring (distance to transport, schools, amenities).

- **Business Impact:** Increased daily qualified lead processing from 300 to 700 at constant audience volume.
- **Stack:** Python, FastAPI, n8n, Webhooks, PostgreSQL, Docker.
